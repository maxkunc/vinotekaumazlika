# Prompt: Landing page „Vinotéka u Mazlíka“ (jednostránkový web se scroll navigací)

## Cíl
Vytvoř moderní, responzivní jednostránkový web (one-page site) pro vinotéku
„Vinotéka u Mazlíka“ v Hradci Králové. Web je jedna dlouhá stránka rozdělená
na sekce, mezi kterými se navigace v headeru plynule scrolluje (smooth scroll,
anchor linky `#sekce`). Dvě právní podstránky (GDPR, kamerový systém) mohou
zůstat jako samostatné route, na které vedou pouze odkazy z patičky — nejsou
součástí hlavního scrollu.

## Doporučený tech stack
- Next.js (App Router) nebo čistě statický HTML/CSS/JS, podle preference
- Tailwind CSS pro styling
- Smooth scroll (`scroll-behavior: smooth` + `scroll-margin-top` na sekcích
  kvůli sticky headeru)
- Sticky/fixed header s aktivním zvýrazněním sekce podle scroll pozice
  (scroll-spy)
- Mobilní hamburger menu pro navigaci

## Jazyk a tón
Celý obsah webu je v češtině. Tón: útulná, rodinná vinotéka s důrazem na
kvalitu, osobní přístup a poměr cena/kvalita. Zachovej diakritiku všude.

## Design & UX poznámky
- Sticky header s scroll-spy (aktivní odkaz se zvýrazní podle viditelné
  sekce)
- Plynulé fade-in/scroll animace při vjezdu sekcí do viewportu
- Plně responzivní (mobil, tablet, desktop)
- Sekce s nabídkou (stáčená vína, lahvová vína) navrhni jako komponenty
  s jasně oddělenými placeholder daty, aby šly později snadno napojit na
  administraci/CMS
- Dodržet korektní sémantické HTML (`<header>`, `<nav>`, `<section id="...">`,
  `<footer>`) kvůli přístupnosti a SEO
